# TINEHNEMI

## Descripción

TINEHNEMI es una aplicación móvil educativa orientada al aprendizaje del náhuatl y a la preservación cultural.

La aplicación está diseñada para funcionar sin conexión a Internet, facilitando el acceso a recursos educativos en diferentes contextos.

## Funcionalidades principales

- Aprendizaje básico.
- Vocabulario y frases en náhuatl.
- Pronunciación y práctica auditiva.
- Juegos educativos.
- Historias y leyendas indígenas.

## Propósito

TINEHNEMI busca contribuir al aprendizaje de la lengua náhuatl y fortalecer la identidad cultural mediante una herramienta educativa accesible.
